# watchy-cart

E-ink 腕時計 [Watchy](https://watchy.sqfmi.com/) v3 を、M-VAVE FM-1 用のファームウェア「カートリッジ」にするファームです。
時計を USB で FM-1 に挿し、一覧からパッケージ（`.fwsc`）を選ぶと、時計が書き込みます。切り替える場面でパソコンは要りません。

## これはテスト版です

v0.36 は初期のテスト版です。完成した道具としてではなく、見てもらい、試してもらうために公開しています。

- 書き込みを確認したのは **FM-1 1 台と Watchy 1 台**、下の表の 2 経路だけです。それ以外は未検証です。
- 失敗することがあります。失敗すると FM-1 をパソコンから復旧する必要が出るので、試す前にパソコン側のインストーラーを用意してください。
- 動作・メニュー・保存の形式は、版が上がると予告なく変わることがあります。
- ルーター経由で時刻を合わせるとき、時計は日本時間（UTC+9）固定です。
- 時計の画面は英語、Wi-Fi のページとソースのコメントは日本語です。
- 報告は Issues へ。試した経路（どのファームからどのファームへ）、watchy-cart の版、時計に出た表示を書いてください。

自己責任で使ってください。M-VAVE、SQFMI、各ファームの作者とは無関係の個人プロジェクトです。

### M-VAVE Open 系は一方通行

M-VAVE Open を土台にしたファームは `FM-1_8000000`〜`FM-1_8000999` を名乗り、更新を受ける前に事前の手続き（arm）が要ります。watchy-cart はこれを実装していません。その状態の FM-1 に挿すと `open firmware: / use PC installer` と表示して何も書きません。抜けるにはパソコン側のインストーラーを使います。
つまり、時計から**入れる**ことはできても、時計で**戻す**ことはできません。

## ファームウェアは同梱しません

このリポジトリに `.fwsc` は含めず、追加もしません。各ファームは作者のものです。使うパッケージは自分で、Wi-Fi 経由で時計に入れます。

上限：最大 8 本、保存領域は合計 約 4.9MB。拡張子が `.fwsc` で、FM-1 用と確認できたファイルだけ保存されます。

## Wi-Fi でパッケージを入れる

時計が小さな Web ページを出し、そこでパッケージを追加・削除します。つなぎ方は 2 通りです。

### A. WiFi direct（ルーター不要。最初はこちら）

1. 時計で：ホーム → **WiFi / Net** → **WiFi direct**。画面に `watchy-cart / (no password) / 192.168.4.1` と出ます。
2. スマホかパソコンで Wi-Fi **watchy-cart**（パスワードなし）につなぎます。インターネットには出られないので、接続を続けるか聞かれたら「続ける」を選びます。
3. ブラウザで `http://192.168.4.1` を開きます。
4. `.fwsc` ファイルを選んで **置く** を押します。表に製品名とサイズ付きで並びます。**削除** で消せます。
5. 時計の DOWN を長押しして終了。時計が再起動し、カートリッジの一覧に出ます。

### B. WiFi router（時計を家の Wi-Fi につなぐ）

1. 最初に 1 回だけルーターを登録します。A の方法でページを開き、ルーターの欄で名前を選び、パスワードを入れて保存します。使えるのは 2.4GHz だけです。
2. 以後は：ホーム → **WiFi / Net** → **WiFi router**。時計がルーターにつながり、時刻を合わせ、IP アドレスを表示します。
3. 同じネットワークの機器から、その IP アドレスか `http://watchy-cart.local` を開きます。
4. A と同じように追加・削除し、DOWN 長押しで終了。

ルーターにつながらないときは、自動で direct に切り替わります。

### Fetch latest（任意）

同じページの **取得元** に、名前と、`.fwsc` そのものを指す `https://` の URL を登録します。作者の GitHub リリースなら：
`https://github.com/作者/リポジトリ/releases/latest/download/ファイル名.fwsc`

ページの **取得**、または時計の **Fetch latest** で、ルーター経由で取り直します（数十秒かかります。2MB まで）。The Firmware Hub からは取りません。

### Wi-Fi の注意

- **ルーターの名前とパスワードは時計本体のフラッシュに、暗号化せずに保存されます。** このソースコードには入っていません。時計を手にしてフラッシュを読める人は取り出せます。貸す・売る・譲る前に消してください：ページを開き、ルーターの欄を名前を空にして保存します。パソコンからフラッシュ全体を消去しても消えます。
- 自分の時計のフラッシュを吸い出したファイルは共有しないでください。パスワードが含まれます。
- **WiFi direct にはパスワードがなく、ページにログインもありません。** 動かしている間、電波の届く範囲の誰でも `watchy-cart` につないで、パッケージの追加・削除やルーター設定の変更ができます。ページに出るのは保存済みパスワードの文字数だけで、中身は出ません。必要なときだけ動かし、終わったら DOWN 長押しで終了してください。
- ページは暗号化なしの `http` です。router のときは、動かしている間、同じネットワークの誰でも開けます。

### 「！」の印

M-VAVE Open 系のパッケージには、ページ上で **！** が付きます。書き込む前に、上の「M-VAVE Open 系は一方通行」を読んでください。

## ハード

- Watchy v3（ESP32-S3FN8、フラッシュ 8MB、PSRAM なし）
- 時計と FM-1 をつなぐ USB-C ケーブル。時計が USB ホストになります。5V は供給しません。

### 2 ボタンだけで動かしている理由

作者の Watchy は左側の 2 ボタン（Back / Menu）が取れてしまいました。そのため、公式ファームの 4 ボタン操作を、右側の 2 ボタン（UP / DOWN）の短押し・長押しだけで全部できるように書き換えています。左のボタンは一切使わないので、4 つとも付いている Watchy でも同じ操作で動きます。

## 操作

| | 短押し | 長押し |
|---|---|---|
| UP | 上 | 戻る（時計画面ではロック解除 → ホーム） |
| DOWN | 下 | 決定 |

- UP + DOWN を短く：どこからでも時計に戻る。
- UP + DOWN を 3 秒：USB mode。10 秒：強制再起動して USB mode。
- DOWN を押しながら電源投入：USB mode。
- probe / WiFi / USB mode の終了は必ず DOWN（UP は GPIO0 で、押したまま再起動すると ROM ブートローダーに入るため）。

## ビルド

Arduino IDE。スケッチのフォルダ名は `watchy-cart` にします。

- Watchy ライブラリ 1.4.14、Arduino ESP32 core 3.3.12
- Board: **ESP32S3 Dev Module** / Flash Size: **8MB** / USB Mode: **Hardware CDC and JTAG** / USB CDC On Boot: **Enabled** / PSRAM: **Disabled**
- 区切りはスケッチフォルダの `partitions.csv` が自動で使われます。

2 回目以降の書き込みは、時計のメニューで **USB mode** を選んでから。
